# Simple Interest Calculator

A simple Bash script that calculates **simple interest** based on user input.

## Project Name
Simple Interest Calculator

## Description
This project contains a command-line calculator, written in Bash, that computes simple interest. The user is prompted to enter the principal amount, the rate of interest and the time period, and the script displays the calculated interest.

## Formula

```
Simple Interest = (Principal x Rate x Time) / 100
```

| Input | Description |
|-------|-------------|
| Principal (P) | The initial amount of money |
| Rate of Interest (R) | The yearly interest rate, in percent |
| Time Period (T) | The duration, in years |

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/mayureshk481-ship-it/simple-interest-calculator.git
   cd simple-interest-calculator
   ```
2. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
3. Run the script:
   ```bash
   ./simple-interest.sh
   ```

## Example

```
Simple Interest Calculator
Enter the principal amount: 10000
Enter the rate of interest (%): 5
Enter the time period (years): 2
Simple Interest = 1000.00
```
